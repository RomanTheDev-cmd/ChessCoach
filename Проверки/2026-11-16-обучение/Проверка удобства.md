# 2026-11-16 — (Codex) Проверка раздражающих факторов всего приложения

Проверены пользовательские сценарии главного экрана, задач, игры, разбора, дебютов, школы, статистики/калибровки и оформления. Основание: замечания Романа, чтение всех экранных ветвей, CUA на временном профиле; ограничения перечислены ниже.

| Фактор | Изменение и проверка |
| --- | --- |
| Повторы почти той же задачи | Сравнение позиций, паузы между личными задачами, смена темы/мотива. Симуляция 30 задач дала 30 разных ID, все четыре темы и 1–3 хода. |
| Пустые/повторяющиеся подсказки | Три уровня помощи по конкретной линии; после ошибки уровень растёт. Кнопка после третьей отключена, переход/пропуск остаётся. CUA и тесты. |
| Успех одновременно критикуется; отсутствующая фигура в тексте | Старый комментарий не используется после решения. Описание создаётся из реальных ходов; протестирован скриншотный тип ошибки с отсутствующей пешкой. |
| «Допустимый» вместо объяснения | Неверный ход сопровождается конкретным ответом соперника, если его можно подтвердить. Запрещённый ход объясняет правило. |
| Техническая речь о расчёте программы | Убрана из игровых объяснений и старых разборов при показе. |
| Фонетика в тексте | Видимые координаты D4 и отдельная подготовка речи. |
| Пропавшая озвучка реакции | Ограничение повторов не применяется к действиям; ручной повтор всегда доступен. Индикатор подготовки озвучки виден сверху. |
| Звук спрятан под доской | Звук и повтор объяснения продублированы в заголовке занятия, в меню автоматической речи нет. CUA. |
| Резкие/схлопнувшиеся ходы | 650 мс движения, пауза 300 мс перед ответом, отложенная перерисовка и последовательность ходов. CUA: игра и рокировка; тесты: задачи/линии/две фигуры при рокировке. |
| Не видно последнего хода | Исходное и конечное поля отмечены тёплым цветом, внутренней рамкой и меткой; сохраняется до следующего хода и восстанавливается при возврате. CUA. |
| Нельзя рассмотреть предлагаемый вариант | В разборе доступны «Мой вариант» и «Лучший вариант», пошаговый просмотр вперёд/назад с подсветкой. CUA и тест. |
| Разбор внезапно переключает экран | Фоновое завершение сохраняет разбор и сообщает о нём, не уводит из другого режима. |
| История растягивает страницу | История дебюта свернута; последние 20 отделены от более ранних, старые не удаляются. В истории партий явно указано ограничение показа. |
| Непонятная статистика решений | Задачи больше не смешиваются с пройденными уроками в счётчике и диаграмме решений. |
| Случайный сброс оценки | Явное подтверждение с пояснением сохранения истории; проверена отмена. |

Осталось учитывать: новые динамические реплики при первом синтезе могут готовиться несколько секунд; показывается статус, затем используется кэш. Нет оценки всех фраз на слух и длительной проверки раздражителей в ежедневной работе. Полный перебор интерфейса всех сорока уроков вручную не выполнялся; структура/правила курсов проверяются тестами. Длительность 650 мс выбрана по просьбе замедлить ходы, субъективное принятие Романом ещё не получено. Ходы в пошаговом просмотре разбора меняются по нажатию; плавное перемещение предназначено прежде всего для игры/задач/учебной практики.

Детектор impeccable выполнен по изменённым UI-файлам, результат [] в design-detect.json. Это механическая проверка, не доказательство отсутствия раздражителей. Дизайн сохранён: светлый современный минимализм, без перестройки навигации и новых лишних панелей.
