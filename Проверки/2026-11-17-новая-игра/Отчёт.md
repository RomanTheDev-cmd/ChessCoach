# 2026-11-17 — (Codex) Исправление кнопки «Новая игра», 1.5.1

## Сделано

Подтверждена причина: кнопка «Новая игра» была связана с start-game; startGame при существующей незавершённой партии возвращался к ней. Запись DSH о том, что такое нажатие начинает новую, не соответствовала реальному поведению. Дополнительно установленная копия имела ту же старую реализацию.

Теперь новая игра вызывает отдельное действие new-game и startGame({restart:true}); продолжение текущей остаётся отдельным действием. Прежняя партия с ходами сохраняется в interruptedGames без начисления поражения и без изменения рейтинга. В разделе «Игра» она доступна в свёрнутом списке «Незавершённые партии» через «Продолжить». Пустые доски без ходов не накапливаются. Завершённая партия с незавершённым разбором также сохраняется и при восстановлении возвращается к разбору.

Защищены переходы во время расчёта и отказ сохранения: новая партия не заменяет текущую, пока идёт ход/разбор; ошибка записи откатывает смену игры. Кнопка новой партии на завершённом экране отключена во время разбора; лишняя «Сдаться» на завершённой партии убрана.

Версия увеличена до 1.5.1, сборка помещена в новую versioned release/1.5.1 без удаления прошлой. Тестовые временные файлы хранилища теперь перемещаются в Корзину вместо безвозвратного удаления, согласно актуальному общему AGENTS.md.

После правки шесть сценариев проходят — green.txt: новый ID/начальная доска/сохранение ходов без штрафа, обычное продолжение, восстановление через кнопку, блокировка во время расчёта, откат при отказе записи, сохранение ожидающей разбора партии.
- Полный npm test: 96 успешно, 0 ошибок, exit 0 — tests.txt/tests.exit.
- npm run build и package проходят. Проверенные файлы установленной 1.5.1 совпадают с рабочей сборкой по SHA-256; codesign --verify --deep --strict проходит.
- Функция startGame взята непосредственно из установленного dist/app.js и выполнена изолированно с настоящими replayMoves/ProgressStore: новая позиция сохраняется, прежняя партия остаётся с ходами E4/E5 и восстанавливается. Это проверка установленного кода, не нажатие на живое окно.
- Пользовательский progress.json при установке не изменился; хэш и резервная копия 1.5.0 — installation.json. Тестовые данные отдельно в этой папке.
