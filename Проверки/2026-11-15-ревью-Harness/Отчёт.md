# 2026-11-15 — (Codex) Проверка доработок Harness / DSH 1.4.0

Оценка: полезные улучшения, но доработку нельзя считать завершённой. Подтверждены три дефекта. Код приложения при проверке не изменялся.

## 1. P1 — Закрытие подтверждается даже при ошибке сохранения

`src/app.mjs:24,161`, `main.cjs:26,29`. Функция save перехватывает ошибку и не передаёт её вызывающему коду. Обработчик закрытия после этого всё равно вызывает confirmClose. Несохранённый прогресс может потеряться, уведомление исчезнет вместе с окном.

Воспроизведение: выполнены настоящие функции save и onCloseRequest из текущего исходника в VM; на границе coach.save подставлен отказ ENOSPC. Результат closeConfirmed=true. Физическое заполнение диска не выполнялось. Исправление должно передавать результат/ошибку сохранения и предотвращать выход при отказе, включая страховочный таймер.

## 2. P2 — Закрытие во время оценки последнего хода теряет сессию практики

`src/app.mjs:120,150–155,161`. На шестом своём ходе OpeningSession уже имеет phase=done, но courseSquare ещё ждёт оценку движка. leaveStudy обнуляет study и не записывает done при page=0. После возврата движка проверка study!==s прерывает завершение; история остаётся пустой.

Воспроизведение: реальная OpeningSession, курс и существующий fixture opening-practice.json; выполнен реальный leaveStudy через callback закрытия в VM. Получены phaseBefore=done, historyCount=0, studyCleared=true, closeConfirmed=true. Это проверка логики на границе ожидания, а не полный реальный Cmd+Q с движком. Требуется согласовать закрытие с незавершённой оценкой либо надёжно сохранить незаписанную сессию. Условия leaveStudy существовали ранее; новый механизм закрытия унаследовал этот дефект.

## 3. P2 — Анимация начинает движение с противоположной стороны

`src/app.mjs:50`. После перерисовки картинка уже находится в конечной клетке. Для исходного смещения требуется source−destination; сейчас стоит destination−source. При e2→e4 фигура начинает движение со стороны e6 и едет обратно к e4.

Воспроизведение реальной slidePiece с моделью DOM-координат: исходная Y=500, конечная Y=340, получен translateY=−160 и стартовая Y=180 вместо 500. Замер изменения transform сам по себе не подтверждает правильность траектории.

## Не проверено

Полное прослушивание реплик, длительная повседневная работа, точность оценки уровня по реальным партиям, другой Mac/Intel, редкие ходы глазами в анимации, реальное заполнение диска и настоящий Cmd+Q в момент последней оценки. Возобновление прерванного урока с той же позиции не реализовано новым механизмом: он записывает прерывание в историю.

Результат независимой проверки кода другим агентом совпал с двумя дефектами сохранения; вывод основан также на собственных воспроизведениях Codex. Для продолжения: устранить три дефекта, добавить регрессии именно на callback закрытия и координаты, повторить проверки, пересобрать и сверить установленную версию.
