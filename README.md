# Шахматный тренер

Личное приложение для Mac: партии со Stockfish, задачи по уровню и ошибкам, разбор, дебютные курсы, школа шахмат и озвучка учителя. Версия 1.5.0 (2026-11-16).

Настольное приложение на Electron: локальный HTML/CSS/JavaScript, без сервера, регистрации и облачной синхронизации. Прогресс хранится только на этом Mac.

## Что он делает (простыми словами)

1. **Оценка уровня.** Три зачтённые партии дают начальную внутреннюю оценку. Короткая сданная партия (меньше восьми ваших ходов) в неё не входит; настоящий мат засчитывается. Оценку можно пройти заново, прежняя история при этом сохраняется.
2. **Игра.** Без часов, против Stockfish с изменяемой сложностью. Партия сохраняется после ходов. После завершения — разбор каждого вашего хода, лучший ход и продолжение; ваши ошибки становятся персональными задачами.
3. **Задачи.** 5512 стартовых позиций, включая 5500 из открытой базы Lichess (CC0, https://database.lichess.org/#puzzles): 914 на один ваш ход, 2811 на два, 1775 на три. Соперник отвечает автоматически. Есть подсказки и пропуск. Подбор учитывает уровень, оценки по темам, успешность, подсказки, попытки и давность показа; недавние и только что решённые позиции не повторяются.
4. **Дебюты.** Пять курсов по восемь последовательных уроков: идея, основной вариант, планы сторон, два других варианта, типичные ошибки, переход к середине игры и свободная практика с компьютером. Всего 40 уроков и 15 учебных линий. Следующий урок открывается после проверки предыдущего; к пройденным можно возвращаться. Это учебный минимум, не исчерпывающая теория дебютов.
5. **Школа шахмат.** Короткая и длинная рокировка, взятие на проходе, превращение, вилка, связка, мат по последней горизонтали, взаимодействие короля и ладьи.
6. **Мой прогресс.** График внутренней оценки, результаты задач, освоение тем, история и разборы. Примеры не подставляются: графики наполняются вашими данными.
7. **Вид доски.** Три палитры и три набора фигур; по умолчанию собственные плоские геометрические фигуры.
8. **Учитель.** Объясняет открытое упражнение, комментирует попытку и решение, затем следующую задачу. Голос TeraTTSv2 `ru_m1`; речь всегда дублируется текстом. Автоповтор одной и той же реплики ограничен паузой 30 минут, ручная кнопка повторения обходит паузу.

Озвучка: 379 обязательных текстов уже созданы и входят в проект; новые фразы синтезируются локально и кэшируются. Для новых фраз нужно установленное на этом Mac окружение `~/.local/share/freelearn-video/.venv-tts-comparison` и веса `~/.cache/freelearn-video/teratts-v2` — в приложение они не включены. Готовые реплики работают без запуска модели.

## Установка и запуск

Установленное приложение: `/Applications/Шахматный тренер.app` (ссылка также на Рабочем столе). Сборка для Apple Silicon; отдельной сборки для Intel и нотарификации Apple нет.

Сборка из исходников:

```bash
npm ci            # зависимости (chess.js, stockfish, Electron, esbuild, packager)
npm run build     # esbuild: src/app.mjs → dist/app.js
npm start         # запуск из исходников
npm run package   # сборка .app для arm64 в release/ (имя «Шахматный тренер», id com.roman.chess-coach)
```

`npm run package` копирует `main.cjs`, `preload.cjs`, `dist`, `audio` и служебные файлы в `package-stage` и собирает `.app` через `@electron/packager`. Готовая сборка занимает около 300 МБ и в Git не входит.

## Где хранится прогресс

`~/Library/Application Support/Шахматный тренер/progress.json`, рядом резервная копия `.bak`. Экспорт — кнопка в «Мой прогресс». Журнал ошибок (сбои старта, сохранения, движка, разбора и озвучки) — `~/Library/Application Support/Шахматный тренер/logs/Шахматный тренер.log`, ограничен 1 МБ; открывается кнопкой «Журнал ошибок».

Если сохранение повреждено или имеет неизвестный формат, автоматическая запись блокируется, и исходный файл не заменяется свежим профилем.

## Разработка

- `main.cjs`, `preload.cjs` — окно Electron и безопасный мост в страницу.
- `src/` — исходники интерфейса и логики: `core.mjs` (партии и разбор), `engine.mjs` (Stockfish), `puzzle.mjs`, `decision.mjs` (подбор задач), `opening-*.mjs` (курсы), `lessons.mjs` (школа), `narration.mjs` (озвучка), `store.cjs` (сохранение), `ui.mjs` (анимация ходов).
- `dist/` — собранная страница и движок; `dist/app.js` пересобирается `npm run build`.
- `audio/` — 389 готовых mp3 и описаний; `scripts/prevoice.mjs`, `scripts/voice.py` — подготовка и синтез реплик; `scripts/verify-audio.mjs` — проверка файлов.
- `scripts/package.mjs` — сборка `.app`; `scripts/import-puzzles.mjs` — импорт базы задач.

## Проверки

```bash
npm test          # node --test tests/*.test.mjs
```

По журналу проекта на 2026-11-16 проходят 90 проверок: правила шахмат и легальность всех 5512 решений, полные партии настоящим Stockfish, 40 дебютных уроков, подбор задач и разнообразие, сохранение и защита от повреждения профиля, гонки закрытия и окно ожидания движка, озвучка и анимация ходов. Сборка совпадает с `dist`. Отчёты, снимки и журналы проверок — в папке `Проверки/`.

## Ограничения

- Внутренняя оценка не калибрована на выборке игроков и не равна рейтингу FIDE или Lichess; уровень подстраивается приблизительно.
- Разбор использует короткий поиск и может упускать глубокие продолжения; объяснения построены на шаблонах и конкретных ходах движка.
- Естественность и все ударения озвучки на слух не проверялись — только файлы, хэши и декодирование.
- Полные партии с оценкой в интерфейсе и длительное ежедневное использование проверены ограниченно; отдельной сборки для Intel нет.
- Готовые реплики работают всегда, синтез новых фраз зависит от локального окружения TTS (см. выше).
